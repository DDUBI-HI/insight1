## 3-1. 강사풀 PPT 에 새 강사 자동 추가 (TEAM 2)

지정한 폴더에 새 강사 프로필(PDF·PPTX·DOCX)이 들어오면, 강사풀 PPT(예: `MindAILab AI/AX 전문강사풀`)와 **같은 규격·디자인**으로 한 장을 추가한 새 버전을 만듭니다.

- 기존 강사 장(첫 강사 장)을 그대로 복제해 글만 바꿉니다 → 글꼴·색·칸 위치가 똑같습니다.
- 칸마다 기존 65명의 글 길이를 재서, 넘치지 않게 Claude 에게 글자 수를 지정합니다. 넘치면 한 번 더 고쳐 씁니다.
- "강사풀 한눈에 보기" 표에 한 줄 추가(자리가 없으면 표 장을 하나 더), "65인·65명" → "66인·66명", 쪽 번호도 다시 맞춥니다.
- 개인 연락처는 넣지 않습니다(이 PPT 의 규칙). 이미 있는 이름이면 추가하지 않고 알려 줍니다.
- 결과는 승인함에 **미리보기 그림**과 함께 올라옵니다. [새 버전으로 저장]을 누르면 같은 폴더에 **버전 번호를 하나 올린 새 파일**로 저장됩니다(예: `…전문강사풀_v6.pptx` → `…전문강사풀_v7.pptx`, **원본은 그대로**). 다음 강사는 그 새 버전(v7)에 이어서 추가하고 v8 로 저장합니다.
- 강사풀 PPT 를 감시 폴더 안에 두어도 됩니다. 이름이 같은 `…_v숫자.pptx` 파일은 강사 프로필로 보지 않습니다.
- 강사별 폴더 정리와 강사풀(CSV) 반영안도 함께 승인함에 올라옵니다.

**설정 (한 번만)** — PowerShell 에 붙여 넣습니다(경로는 실제 위치로):

```
node C:\AI-OFFICE\insight1\ai-office\bridge\set-config.mjs --deck "<강사풀 PPT 전체 경로>" --watch "<감시할 폴더 전체 경로>"
```

그다음 `STOP-AI-OFFICE.bat` → `START-AI-OFFICE.bat`. 연결 상태 탭의 "강사풀 PPT", "폴더 감시" 줄이 초록이면 준비 끝입니다.
- 감시를 켤 때 폴더에 **이미 있던 파일은 건너뜁니다**(새로 들어온 파일만 처리).
- OneDrive 가 파일을 다 받을 때까지 기다렸다가(2분 간격으로 크기 확인) 처리합니다.
- 감시 끄기: `node C:\AI-OFFICE\insight1\ai-office\bridge\set-config.mjs --watch-off`
- 폴더 감시 없이 한 건만: 업무 패널 → 업무 요청 → "강사풀 PPT 에 새 강사 장 추가"

2. 설치 때 자동 시작을 켰다면 AI 사무실은 이미 켜져 있습니다 → 바탕 화면 **"AI 사무실 열기"** 만 누르세요.

## 6. 안 될 때

| 증상 | 해결 |
|---|---|
| n8n 에서 AI 사무실로 접속 실패 (`TEST-CONNECTION.bat` ②번 실패) | `ai-office\config.json` 의 `"bindHost": "127.0.0.1"` 을 `"0.0.0.0"` 으로 바꾸고 STOP → START. Windows 방화벽이 물으면 **개인 네트워크만** 허용. 토큰이 없으면 작업을 시킬 수 없지만, 같은 네트워크에서 3D 화면은 볼 수 있게 됩니다. |
| "claude 실행 파일을 찾지 못했습니다" | PowerShell 에서 `where.exe claude` 로 나온 경로를 `config.json` 의 `claudePath` 에 넣습니다(역슬래시는 `\\` 두 번). |

## 7. 안전 장치 (지키는 약속)

- **기존 n8n 워크플로·Claude 에이전트는 바꾸지 않습니다.** n8n 은 새 워크플로만 추가하고, 에이전트는 복사본에서 돌립니다.
- **정해진 작업만** 실행합니다. n8n 이나 다른 프로그램이 임의의 명령을 실행시킬 수 없습니다.
- AI 직원이 쓸 수 있는 도구는 작업마다 정해져 있습니다(예: 문의 분석은 도구 없이 읽기만, 범용화는 slide-svg 스크립트와 `output` 폴더 쓰기만). git push 는 카드뉴스 완성 단계에서만 허용합니다.
- **고객사 메일 발송·인스타그램 공개 게시는 자동으로 하지 않습니다.** 승인해도 "직접 보내기/올리기" 안내만 합니다.
- 강사풀 같은 **중요 파일은 승인 후에만, 백업한 다음** 바꿉니다. 결과 파일은 같은 이름이 있으면 `_2` 를 붙여 새로 만듭니다.
- 토큰·비밀값은 코드나 설정 파일이 아니라 `C:\AI-OFFICE\office-data\secret\` 에만 있고, 화면에 출력하지 않습니다(복사는 `COPY-TOKEN.bat`).
- AI 사무실 서버는 이 PC(127.0.0.1)에서만 열리고, 다른 웹사이트가 몰래 부르지 못하게 막습니다.
- `backups` 폴더와 `agents\slide-svg` 복사본에는 기존 교육문의 자동화의 `.env`(웹훅 비밀값)도 함께 복사됩니다. 이 폴더들은 다른 사람과 공유하거나 클라우드에 올리지 마세요.
