# DESIGN.md — Lecture Video (강의 영상 배경)

> 강사 영상을 오른쪽에 합성하는 **교육 영상용 배경 슬라이드** 디자인 시스템.
> 출처: 사용자가 제공한 「공공기관/지자체 템플릿」 PDF 23장 — 색은 PDF 렌더에서 픽셀 샘플링, 구성은 페이지별로 재현.
> 구현: `scripts/lskit.py` (토큰·셸·레이아웃 SSOT) · 입력 형식: `references/deck-format.md` · 토큰 JSON: `theme.json`.

---

## 1. 최우선 규칙 — 오른쪽 30 % 는 강사 자리

```
x=0        56                    456                   856  896                1280
 ┌─frame──────────────────────────────────────────────────────┬─────────────────────┐
 │  ┌──────────── 콘텐츠 존 (폭 800, 중심 456) ────────────┐  │                     │
 │  │ eyebrow · 제목 · 룰                                  │  │   강사 영상 합성     │
 │  │                                                     │  │   (배경만 보인다)    │
 │  │ 본문 레이아웃                                        │  │                     │
 │  │                                                     │  │   콘텐츠 금지        │
 │  │ 룰 · brand · GM · 쪽번호                             │  │                     │
 │  └─────────────────────────────────────────────────────┘  │                     │
 └────────────────────────────────────────────────────────────┴─────────────────────┘
                                                           ↑ 40px 여백   ↑ x=896 (70 %)
```

- **x ≥ 896 에는 텍스트·도형·아이콘·이미지·룰을 두지 않는다.** 프레임·흰 패널·상단/하단 띠 같은 **배경만** 전체 폭으로 깐다 (강사 뒤로 자연스럽게 이어지도록).
- 콘텐츠 존은 **x 56–856**. 헤더(eyebrow·제목·룰)와 푸터(룰·GM·쪽번호)도 존 안에서 끝나고, 가운데 정렬 요소는 슬라이드 중심(640)이 아니라 **존 중심 456**에 맞춘다.
- `lskit`의 모든 primitive가 bounding box를 기록하고, 페이지를 쓸 때 x > 896 이 하나라도 있으면 **빌드 실패(SafeZoneError)**. 856–896 구간은 경고.
- 납품 전 `finish.py`가 만드는 `zoneN.png`(강사 실루엣 오버레이)로 눈으로도 확인한다.

## 2. 무드

- 깔끔하고 간편한 공공기관 톤 — 페리윙클 프레임, 넉넉한 흰 여백, 둥근 소프트 카드, 점선 구분, 굵은 잉크색 제목.
- 한 장 = 한 메시지. 영상 시청자는 화면을 오래 읽지 않는다 → 본문 ≥ 16px, 문장은 짧게, 강조는 한 군데.
- 피할 것: 그라디언트·그림자·글로우, 무지개 색, 이모지, 사진 위 글자, 오른쪽까지 꽉 찬 표.

## 3. 팔레트 (PDF 샘플링, 이 8색만 사용)

| 토큰 | HEX | PDF 출처 | 용도 |
|---|---|---|---|
| `accent` | `#717FCB` | 프레임·룰·eyebrow·번호 | 단일 액센트: 프레임, 룰, 번호, 채운 원·박스, 강조 문장 |
| `ink` | `#22294A` | 제목·큰 숫자 | 제목, 강한 텍스트, 꺾쇠(›) |
| `body` | `#636573` | 설명 문장 | 본문·설명 |
| `band` | `#E9E9F2` | 상단 띠·하단 띠 | 상단 띠, 표지/엔딩 하단 띠, 키워드 양옆 원 |
| `soft` | `#F6F6FE` | 카드 배경 | 카드·패널, 간지 바깥 여백 |
| `mid` | `#B6BDDF` | 간지 하단 띠·흐름 2단 | 간지 하단 띠, 타임라인 중간 단계, 차트 눈금선, 표 행 구분선 |
| `placeholder` | `#DBE1F3` | 이미지 자리 | 이미지 플레이스홀더, 표 강조 행 |
| `white` | `#FFFFFF` | 패널 | 패널, 채운 도형 위 글자 |

- 대비: `ink`/`body` on white ≥ 5.9:1. **흰 글자 on `accent` = 3.7:1 → 15px 이상 + 500 이상 굵기(17px 이상이면 400 가능).** `accent` 글자 on white도 같은 이유로 16px 이상(eyebrow·번호·강조 문장).
- 한 페이지 강조(채운 `accent` 블록 + `accent` 강조 텍스트)는 2개 이내. 틴트 3단(soft → mid → accent)은 단계 표현에만.
- 빌드가 `.theme-color-allow`에 이 8색을 기록 → `svg_quality_checker --strict-theme`가 다른 색을 잡는다.

## 8. Do / Don't

- Do: 강의 원고의 한 단락 = 한 장. 길면 장을 나눈다 (영상은 넘기는 비용이 0).
- Do: eyebrow에 강의 목차 번호(`1-1. 개인정보 정의`)를 넣어 시청자가 위치를 안다.
- Do: 대본은 `notes`(발표자 노트)에 — 녹화할 때 프롬프터로 쓴다.
- Don't: 오른쪽 30 %에 쪽번호·로고·출처를 두지 않는다 (강사 몸에 가린다).
- Don't: accent 위에 15px 미만 흰 글자를 두지 않는다.
- 주의: 영상 편집에서 자막을 하단 중앙에 얹으면 GM 줄(y≈674)과 겹친다 — 자막은 강사 영역 하단(x ≥ 896)에 두거나, GM을 짧게 써서 자막 폭과 겹치지 않게 한다.
