# 교육 영상 배경 PPT 디자인 시스템 (edu-video) — 정본 규칙

강사 영상을 오른쪽에 합성하는 **온라인 교육 영상의 배경 슬라이드** 규칙이다.
Insightlearning 테마(네이비 `#012281`, Pretendard) 위에서 동작하며, 루트 `CLAUDE.md`의 슬라이드 엔진 규칙(1280×720, 단일 액센트, 이모지 금지, 네이티브 SVG→PPTX, 직렬 실행)을 그대로 따른다.
PDF 판: `.claude/skills/edu-video/design-system.pdf` (`scripts/make_design_pdf.py`로 다시 만든다).

## 1. 원칙

1. **70 / 30 화면 분할.** 왼쪽 70%는 콘텐츠, 오른쪽 30%는 강사 영역으로 비워 둔다.
2. **큰 글씨.** 저시력 학습자를 기준으로 크기를 정한다. 28px(21pt)보다 작은 글자는 없다.
3. **한 화면에 한 메시지.** 항목은 4개까지, 항목 하나는 2줄까지만 쓴다. 넘치면 화면을 나눈다.
4. **라인 일러스트.** 네이비 3px 외곽선, 흰 면, 연한 블롭(`#E0EDF3`) 하나에 반짝이·점 같은 작은 장식을 더한다. 스톡 사진·클립아트·회색 목업은 쓰지 않는다.

## 2. 화면 구조 (1280×720, 영상 1920×1080 = ×1.5)

| 영역 | 좌표 | 규칙 |
|---|---|---|
| 콘텐츠 영역 | x 64–848 (폭 784) | 모든 텍스트·도형·일러스트 |
| 안전 여백 | x 848–872 | 아무것도 넣지 않는다 (검사 기준 x ≤ 872) |
| **강사 영역** | **x 896–1280 (30%)** | 비워 둔다. `stage: tint`이면 연한 네이비 `#E0EDF3` 면, `plain`이면 흰색 |
| 라벨 pill | y 40–85 | `1-1. 개인정보 정의` 같은 차시 번호·소단원명, 28px Bold |
| 제목 | 기준선 y 140, 44px Bold | 한 줄, 한글 약 17자까지 |
| 구분선 | y 168 | 회색 2px 선 위에 네이비 바 88px |
| 본문 | y 196–552 | 레이아웃마다 세로 중앙 정렬 |
| 핵심 한 줄 (GM) | y 568–628 띠, 30px Bold 네이비 | 모든 콘텐츠 화면에 필수. 제목을 반복하지 말고 so-what을 쓴다. 한글 약 22자까지 |
| **자막 안전 영역** | **y 644–720** | 비워 둔다. 영상 편집 때 자막이 들어간다 |

표지·챕터·엔딩은 네이비 전면 셸을 쓴다. 이때도 콘텐츠는 x ≤ 872, y ≤ 644 안에 둔다(강사 위치가 화면마다 같아야 한다).

## 3. 타이포그래피 (Pretendard 풀 체인)

| 토큰 | px (캔버스) | pt (PPT) | 1080p 영상 px | 굵기 | 용도 |
|---|---|---|---|---|---|
| display | 64 | 48 | 96 | Bold | 표지 제목, 엔딩 |
| chapter | 56 / 128 | 42 / 96 | 84 / 192 | Bold | 챕터 제목 / 챕터 번호 |
| emphasis | 52 | 39 | 78 | Bold | 강조(emphasis) 문장 |
| h1 | 44 | 33 | 66 | Bold | 슬라이드 제목, 정의의 강조 구 |
| h2 | 36 | 27 | 54 | Regular/Bold | 정의 문장, 퀴즈 질문, 인용문 |
| **body** | **32** | **24** | **48** | Regular/Bold | **본문 기본** |
| key | 30 | 22.5 | 45 | Bold | 핵심 한 줄 |
| **min** | **28** | **21** | **42** | Regular/Bold | 라벨·보조 설명. **이보다 작은 글자 금지** |

- 줄 간격 1.35–1.45. 한 줄 길이는 본문 32px 기준 한글 약 22자.
- PPTX에서 굵기는 Regular(400)와 Bold(700) 두 가지만 쓴다. Light·Thin은 쓰지 않는다.
- 줄바꿈은 빌더가 균형 있게 나눈다. 한 단어만 남는 줄이 생기지 않고, `·` 같은 구분 기호로 줄이 시작하지 않는다. 강제 줄바꿈은 ` | `로 한다.

## 4. 접근성 규칙 (저시력·시각장애 학습자)

| # | 규칙 | 검사 |
|---|---|---|
| A1 | 모든 글자 **28px(21pt) 이상**. 본문 32px(24pt) 이상 | 자동 (`evcheck` A1) |
| A2 | 텍스트와 배경의 대비 **6.6:1 이상**. 모든 글자가 WCAG의 '큰 텍스트'(18pt 이상)라서 AAA(4.5:1)를 넘는다 | 토큰으로 보장 (§5) |
| A3 | **색으로만 의미를 전달하지 않는다.** 강조는 굵게 + 네이비 + 하이라이트 바, O/X는 기호 모양(원/엑스)과 머리글 글자로 구분 | 레이아웃 내장 |
| A4 | 한 화면에 본문 항목 **최대 4개**, 항목당 **2줄** | 자동 (FitError) |
| A5 | 강사 영역(x > 872)과 자막 안전 영역(y > 644) **침범 금지** | 자동 (`evcheck` Z1·Z2) |
| A6 | 일러스트 안에 글자를 넣지 않는다. 일러스트는 장식이고, 뜻은 텍스트와 내레이션이 전한다 | 라이브러리 설계 |
| A7 | **화면의 핵심 문구는 강사가 말로도 읽는다.** 전맹 학습자는 화면을 볼 수 없으므로, 슬라이드마다 `say:`(발표자 노트 = 강의 원고)에 핵심 문구를 포함한다 | 노트로 출력 |
| A8 | 깜빡이는 효과·빠른 애니메이션 금지(1초에 3회 이상 깜빡임 금지). 화면 전환은 컷 또는 짧은 페이드 | 편집 가이드 |
| A9 | 얇은 선으로 의미를 전달하지 않는다. 의미 있는 도형은 면 또는 4px 이상 선을 쓴다(O/X 마크 12–13px) | 레이아웃 내장 |

## 5. 컬러 (Insightlearning 토큰만 — 단일 액센트)

| 역할 | HEX | 대비 |

| 배경 | `#FFFFFF` | — |

| 보조 텍스트 | `#595959` | 흰 배경 위 7.0:1 (O/X의 'X' 쪽 머리글 면으로도 쓴다) |
| 구분선 | `#DFDFDF` / `#C2C2C2` | 장식 전용 |

## 6. 일러스트 시스템

- 스타일: 네이비 3px 둥근 외곽선, 흰 면 + `#E0EDF3` 유기적 블롭 1개, 4각 반짝이·점·고리 장식 2–3개. 네이비 셸 위에서는 흰 선, 네이비 면, `#1F375D` 블롭, 스카이 반짝이로 바꾼다.
- 모든 도형은 PowerPoint에서 편집할 수 있는 네이티브 셰이프다. 이미지로 납작하게 만들지 않는다.
- 아이콘(2px Tabler 라인아트)은 작은 기호로만 쓴다. 큰 장면은 일러스트 라이브러리를 쓴다.
- 라이브러리 (`scripts/evkit/illust.py`):

| 이름 | 장면 | 추천 용도 |
|---|---|---|
| `question` | 궁금해하는 학습자 | 정의·개념 질문, 도입 |
| `idea` | 전구 | 핵심 개념, 팁 |
| `shield` | 방패 + 자물쇠 | 보안·보호·준수 |
| `id_card` | 신분증 + 돋보기 | 개인정보·식별 |
| `document` | 문서 + 체크 | 규정·서류·법 조항 |
| `laptop` | 노트북 UI | 시스템·화면 안내 |
| `talk` | 대화하는 두 사람 | 사례·상담·소통 |
| `checklist` | 체크리스트 | 점검·절차 |
| `target` | 과녁 | 학습 목표 |
| `growth` | 성장 차트 | 효과·성과 |
| `book` | 펼친 책 | 학습·이론 |
| `warning` | 경고 삼각형 | 주의·위반 |
| `trophy` | 트로피 | 정리·완료 |
| `mail` | 봉투 + 알림 | 메일·통지 사고 |
| `quiz` | 물음표 카드 + OX | 퀴즈 |
| `graduate` | 학사모 | 표지·수료 |
| `calendar` | 달력 + 시계 | 일정·기한·보관 기간 |

### 기존 템플릿의 옛 요소 교체

| 기존 (참고 PPT) | 문제 | 교체 |
|---|---|---|
| 클립아트 정장 남성(물음표) | 2010년대 스톡 클립아트 느낌, 화풍이 섞임 | `question` 라인 일러스트 (concept 레이아웃) |
| 스톡 단체 사진 | 해상도·초상권 부담, 다른 화면과 톤이 안 맞음 | `talk` 일러스트 (case 레이아웃) |
| 회색 모니터 목업 + 빨간 막대 | 낡은 기기, 액센트 색과 충돌 | 네이비 라인 노트북 프레임 (screen 레이아웃, 캡처 이미지 삽입 가능) |
| 연두 + 네이비 2색, 원형 점선 장식 | 액센트가 두 개 | 네이비 단일 액센트 + 소프트 블롭 |
| 에스코어드림 등 여러 서체 | 서체 혼용 | Pretendard 하나 |
| 14–18pt 본문 | 영상에서 작게 보임 | 본문 24pt, 최소 21pt |

## 7. 레이아웃 (17종) — 필드 정의는 `content-format.md`

| 레이아웃 | 용도 | 일러스트 |
|---|---|---|
| `cover` | 과정·차시 표지 (네이비) | 기본 `graduate` |
| `chapter` | 단원 구분 (네이비, 번호 자동) | 기본 `book` |
| `ending` | 마무리·다음 차시 안내 (네이비) | 기본 `trophy` |
| `agenda` | 학습 순서 2–6개 (`current:`로 진행 위치 표시) | 선택 |
| `concept` | 정의 문장 + 강조 구 (원본 '개인정보란?' 화면) | 기본 `question` |
| `bullets` | 아이콘 + 항목 2–4개 | 선택 |
| `cards` | 2–3열 카드 (`highlight:`로 1개 강조) | — |
| `compare` | O / X, 해당 / 비해당 두 칸 비교 | — |
| `steps` | 2–4단계 흐름 | — |
| `emphasis` | 크게 보여 줄 한 문장 | 선택 (작게) |
| `quote` | 법 조항·정의 인용 | 선택 |
| `stat` | 큰 숫자 하나 | 선택 |
| `case` | 사례 카드 | 기본 `talk` |
| `screen` | 시스템 화면(캡처 삽입) + 단계 | 노트북 프레임 |
| `quiz` | O/X 또는 2–4지 선택 | — |
| `answer` | 정답 + 해설 | — |
| `summary` | 핵심 정리 체크 2–4개 | 기본 `trophy` |

한 계열(family)의 레이아웃이 3장 넘게 이어지면 slide_plan 검증(R4)에서 실패한다. concept → bullets → compare처럼 레이아웃을 섞는다.

## 8. 영상 편집 가이드 (편집자용)

- PPTX → 1920×1080 PNG로 내보낸다(PowerPoint: 파일 → 내보내기 → PNG, 해상도 1920×1080).
- 강사는 크로마키로 따서 **x 1344–1920 px (1080p 기준)** 안에 허리선 위 구도로 배치한다. 손짓이 콘텐츠 영역(x 1308 px 왼쪽)을 가리지 않게 한다.
- 자막은 하단 **y 966–1080 px** 띠 안에 넣는다. 콘텐츠와 겹치지 않는다.
- `stage: tint`는 강사를 네이비 톤 면 위에 세워 화면이 정돈되어 보인다. 강사 의상이 연한 하늘색이면 `plain`을 쓴다.
- 화면 전환은 컷 또는 0.3초 이하 페이드로 한다. 깜빡임 효과는 쓰지 않는다.
