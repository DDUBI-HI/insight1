# 영상 강의 배경 디자인 시스템 (video-slide)

기업교육 템플릿(민트 배경 · 흰 라운드 카드 · 네이비 하단 밴드 · 초록/네이비 투톤 제목)을 **강사 영상 합성용**으로
재구성한 시스템. 값의 정본은 `scripts/vkit/tokens.py` — 이 문서와 다르면 코드가 맞다.

## 1. 원칙

1. **강사가 주인공, 슬라이드는 무대.** 오른쪽 30%는 강사 자리, 하단은 자막 자리다. 슬라이드는 왼쪽 70% 카드 안에서만 말한다.
2. **한 장 = 한 메시지.** 설명은 강사가 말로 한다 — 슬라이드는 키워드와 구조, 자세한 문장은 `notes`(대본).
3. **깔끔하되 심심하지 않게.** 흰 카드 + 넉넉한 여백 위에 일러스트 1개, 색 블록 1종류로 리듬을 만든다.
4. **편집 가능.** 모든 요소는 PowerPoint 네이티브 도형·텍스트 (이미지로 굽지 않음). 일러스트도 도형 묶음이다.

## 2. 화면 영역 (1280 × 720)

```
x 0                        880 896                    1280
┌──────────────────────────────┐ ·                      ┐ y 0
│ 흰 카드 (x 28–880, y 24–)       │ ·   강사 영역            │
│  ┌ 안전 영역 x 64–844 ───────┐  │ ·   x ≥ 896 (30 %)      │
│  │ 헤더  y 58               │  │ ·   배경만              │
│  │ 섹션  y 96  「 … 」       │  │ ·                       │
│  │ 제목  y 150 (38px)       │  │ ·                       │
│  │ 본문  y 186–552          │  │ ·                       │
│  │ GM 필 y 566–606          │  │ ·                       │
│  └──────────────────────────┘  │ ·                       │
└╲______________________________╱┘──────── 무대 탭 y 612 ┤
  네이비 밴드 — 자막 영역 y ≥ 644 (글자 금지, 왼쪽 끝 브랜드만)                 y 720
```

| 영역 | 좌표 | 규칙 |
|---|---|---|
| 강사 영역 | x ≥ 896 | 민트 배경 + 밴드의 올라온 오른쪽 탭(강사가 서는 "무대")만. 글자·아이콘·일러스트·카드 금지 |
| 자막 영역 | y ≥ 644 | 네이비 밴드만. 예외: 왼쪽 탭(x < 176)의 작은 브랜드 표기 |
| 콘텐츠 카드 | x 28–880, y 24–644 | 흰색, 모서리 22 |
| 안전 영역 | x 64–844 | 모든 글자·도형은 이 안에 (`build_deck.py`의 zone_check가 검사) |
| GM 필 | x 104–804, y 566–606 | 콘텐츠 장 필수. 자막 위에 오도록 일반 덱(y 655–705)보다 위 — 프로젝트의 `.gm-band`가 verify_deck에 알려 준다 |

> 강사 영상을 크로마키로 합성할 때 강사의 몸이 x 896–1280 안에 들어오게 촬영한다(허리 위 샷 기준).
> 밴드의 오른쪽 탭은 강사 뒤의 바닥처럼 보이도록 설계했다.

## 3. 색

| 토큰 | 값 | 역할 |
|---|---|---|
| `NAVY` | `#1D3E77` | 제목 뒷부분, 하단 밴드, GM 필, 표 머리, 진한 카드 |
| `GREEN` | `#3EAE8D` | 제목 앞부분, 섹션 라벨, 헤더 라벨, 강조 밑줄, 첫 번째 강조 블록 |
| `TEAL` | `#206C7A` | 두 번째 블록, 보조 강조 |
| `MINT` | `#80C4B0` | 밝은 블록(교차 행, 아래 계층), 점선 연결선 |
| `MINT_BG` | `#DBEEE8` | 바깥 배경, 부드러운 패널, 일러스트 배경 얼룩 |
| `MINT_PALE` | `#EEF7F4` | 표 강조 열, 칩 |
| `LAV` | `#D9DEE8` | 비교의 "이전/아님" 쪽 패널, 질문 행 |
| `INK` / `BODY` / `MUTED` | `#1F2937` / `#595959` / `#8A94A6` | 강한 본문 / 본문 / 캡션·축 |
| `LINE` | `#D5DCE4` | 표·축 헤어라인 |
| `SKIN`, `SKIN_2`, `SUN` | `#F5CBA7`, `#E9B48F`, `#F6C453` | **일러스트 전용** (피부, 그림자, 포인트 노랑). 글자·레이아웃 블록에 쓰지 않는다 |

- 블록 순서: 2개 `GREEN → TEAL`, 3개 `MINT → GREEN → TEAL`, 4개 `MINT → GREEN → TEAL → NAVY`.
- 글자색 규칙: 진한 칠(`GREEN TEAL NAVY`) 위는 흰 글자, 밝은 칠(`MINT MINT_BG LAV`) 위는 **네이비 글자**
  (영상 압축에서 흰 글자 + 민트는 뭉개진다).
- 그라디언트·그림자·글로우 금지. 투명도는 `fill-opacity`로만.
- 이 팔레트는 활성 테마와 다르므로 `build_deck.py`가 프로젝트에 `.theme-color-allow`를 쓴다.

## 4. 서체

Pretendard 단일 (`Pretendard, 'Apple SD Gothic Neo', 'Malgun Gothic', Arial, sans-serif`). 1280×720 기준 px —
1080p 영상에서는 약 1.5배로 보인다.

| 용도 | 크기 / 굵기 | 비고 |
|---|---|---|
| 표지·엔딩 디스플레이 | 52–64 / 900 | 자간 −3% |
| 슬라이드 제목 | 38 / 800 | 투톤, 한 줄. 길면 30까지 자동 축소, 그래도 넘치면 경고 |
| 진술(statement) 리드 | 28 / 500 | 강조 문장 36 / 800 초록 + 밑줄 |
| 카드·항목 제목 | 19–22 / 700 | |
| 본문 | 16–17 / 400 | **최소 15** (표·캡션) |
| 헤더 라벨·페이지 번호 | 13 / 500–600 | 초록 |
| 큰 숫자 | 50 / 800 | stats |

## 5. 컴포넌트 (셸 — `frame.py`)

- **배경**: 민트 전면 + 흰 라운드 카드 + 네이비 무대 밴드 (왼쪽 탭 0–152, 오른쪽 탭 896–1280, 가운데는 y 644).
- **헤더**: 과정명(초록 13px) — 민트 헤어라인 — 페이지 번호 `03` (표지·엔딩은 번호 없음). 원본의 "Presentation · 날짜"를 대신한다.
- **섹션 라벨**: `「 1-1. 개인정보 정의 」` 초록 16px, 카드 가운데.
- **제목**: 카드 가운데, `초록 | 네이비` 투톤 한 줄 (하나의 텍스트 상자 안 tspan — PPT에서 한 번에 편집).
- **GM 필**: 네이비 캡슐 + 흰 원 체크 + 흰 굵은 한 줄. 원본의 "체크 필"을 모든 콘텐츠 장의 결론 줄로 승격.
- **브랜드**: 밴드 왼쪽 탭에 작은 자간 넓은 흰 글자 (`brand:` — 기본 INSIGHTLEARNING, 빈 값이면 생략).

## 6. 일러스트

라이브러리 20종 (`scripts/vkit/illust.py`, 시트: `scripts/gallery.py`). PPT에서 그룹 해제·색 변경이 가능한 도형 묶음.

| 키 | 의미 | 키 | 의미 |
|---|---|---|---|
| `thinking` | 고민·질문하는 사람 | `search` | 돋보기 문서 검토 |
| `presenter` | 강의·설명하는 사람 | `book` | 펼친 책 학습 |
| `idea` | 아이디어 전구 | `calendar` | 달력과 시계 |
| `team` | 팀·구성원 세 사람 | `trophy` | 트로피 성취 |
| `growth` | 성장 막대그래프 | `puzzle` | 맞물린 퍼즐 |
| `target` | 목표 과녁 | `alert` | 주의·경고 |
| `security` | 보안 방패·자물쇠 | `idcard` | 신분증·개인 정보 |
| `checklist` | 체크리스트 | `video` | 영상 재생 화면 |
| `chat` | 대화 말풍선 | `goal` | 정상의 깃발 |
| `laptop` | 노트북 업무 | `steps` | 계단 단계 |

**쓰는 곳**: 표지·섹션·엔딩·`statement`·`points`·`agenda`(기본 켜짐, `illust: none`으로 끔), `illust_cards`(카드당 1개).
표·차트·비교·흐름처럼 구조가 이미 시각적인 장에는 넣지 않는다 — 장당 최대 1개(카드형 제외).

**스타일 계약** (새 드로잉도 지킬 것):
- 200 × 160 박스, 팔레트 색만 (+ `SKIN SKIN_2 SUN`), 플랫 칠, 외곽선 없음.
- 선은 팔·손잡이·기호에만 — 굵고 끝이 둥근 선(`stroke-linecap="round"`).
- 인물은 얼굴 없는 둥근 상반신 (머리 원 + 머리카락 + 목 + 몸통), 표정·이목구비 없음.
- 뒤에 부드러운 민트 얼룩(`blob`) 1개, 작은 반짝임·점 1–3개로 생기를 준다.
- 금지: 그라디언트, 그림자, 3D 광택, 사진, 래스터 클립아트, 이모지.

## 7. 올드 이미지 교체 규칙

참고 파일(PDF/PPT)이나 사용자가 준 자료의 이미지를 슬라이드에 옮기기 전에 판정한다. 하나라도 해당하면 **올드**:

- 외곽선·그라디언트가 있는 2000년대식 클립아트, 광택 3D 인물·아이콘, 물음표 든 정장 인물 같은 스톡 캐릭터
- 흑백·세피아·과채도 스톡 사진, 연출 티 나는 악수·전구·체스말 사진
- 저해상도(표시 폭의 1.5배 미만 픽셀), 워터마크, 계단 현상, JPEG 노이즈
- 워드아트, 베벨·그림자·반사 효과, 팔레트와 충돌하는 원색 이미지

처리:
1. 올드 이미지는 **같은 의미의 라이브러리 일러스트**로 교체 (`illust:` 키 지정; 의미가 애매하면 `auto`).
   예) 물음표 든 정장 클립아트 → `thinking`, 흑백 전구 사진 → `idea`, 원탁 회의실 사진 → `team`/`chat`, 체스말 사진 → `target`.
2. 내용 자체인 이미지(실제 시스템 화면, 제품 사진, 법령 서식, 도표)는 교체하지 않고 `image` 레이아웃으로 둔다.
   저해상도면 사용자에게 원본을 요청한다.
3. 보고에 `원본 페이지 · 원래 이미지 → 교체 일러스트` 목록을 남긴다.

## 8. 글쓰기

- 제목 20자 안팎, 투톤의 앞부분은 주제어, 뒷부분은 관점 (`동기부여의 | 두 가지 유형`).
- 본문 항목은 명사구 또는 짧은 합니다체 한 문장. 카드 설명 2–3줄, 항목 설명 2줄 이내.
- GM은 so-what 한 줄 — 제목 반복 금지 (`네 가지 중 하나라도 빠지면 유효한 동의가 아닙니다`).
- 수치·법령·기한은 출처가 있는 것만. 예시 데이터는 `source: ※ 예시 데이터`로 밝힌다.

## 9. 금지

- 강사 영역·자막 영역에 콘텐츠 배치, 카드 밖 글자
- 이모지, 래스터 클립아트, 사진 배경 위 글자, 그라디언트·그림자
- 한 장에 일러스트 2개 이상(카드형 제외), 같은 레이아웃 3장 연속
- 15px 미만 글자, 7줄 넘는 문단
